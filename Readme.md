# CryptoFlow

**CryptoFlow** --- социальная сеть для общения трейдеров, построенная на
Spring Boot.\
Платформа предназначена для обмена аналитикой, идеями, сигналами и
общения в реальном времени.

------------------------------------------------------------------------

## 🚀 Статус проекта

### ✅ AS IS (Реализовано к 1-му спринту)

-   Спроектирована и реализована база данных (PostgreSQL)
-   Настроена стандартная структура пакетов Spring Boot
-   Созданы базовые Entity-классы
-   Подготовлена архитектурная основа проекта

### 🎯 TO BE (Планируемый функционал)

-   Регистрация и аутентификация пользователей
-   Профили трейдеров
-   Подписки / подписчики
-   Публикации (посты, аналитика, сигналы)
-   Комментарии и лайки
-   Личные сообщения
-   Real-Time обновления через WebSocket
-   Привязка криптовалютных кошельков
-   Обновление курсов валют в реальном времени
-   Кеширование данных
-   Расширенная безопасность (JWT, роли, защита API)

## ▶️ Локальный запуск

### Требования

-   Java 21+
-   PostgreSQL
-   Maven / Gradle

### Шаги

1.  Создать базу данных:

    CREATE DATABASE cryptoflow;

2.  Настроить `application.yml`:

``` yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/cryptoflow
    username: postgres
    password: your_password
  jpa:
    hibernate:
      ddl-auto: update
```

3.  Запустить приложение:


    ./mvnw spring-boot:run
